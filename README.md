# Motoconcho Express

Juego web casual de tres carriles ambientado en Santo Domingo, creado con HTML, CSS y JavaScript.

## Cómo jugar

Pulsa «¡Arrancamos!» y toca a la izquierda o a la derecha, o usa las flechas del teclado, para cambiar de carril. Esquiva las huacas y recoge monedas y plátanos para sumar puntos.

## Jugar en línea

Abre [Motoconcho Express en GitHub Pages](https://jperalta19.github.io/motoconcho-express/). También puedes abrir `index.html` en tu navegador.
